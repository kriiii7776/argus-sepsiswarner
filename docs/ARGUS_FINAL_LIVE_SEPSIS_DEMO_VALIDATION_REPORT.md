## 2. Phase 1 & 2 — Frontend/Backend Connectivity Resolution

### Root Cause Analysis
During initial diagnostic checks, host browser connections to `http://localhost:8000/api/v1/health` and `ws://localhost:8000/api/v1/ws/stream` timed out. Inspection of Windows network bindings revealed that `localhost` resolved to IPv6 loopback (`[::1]:8000`), which was intercepted by WSL2 host relay (`wslrelay.exe`, PID 27248). `wslrelay` accepted TCP sockets on `[::1]` but stalled request payload forwarding to the Docker engine.

### Configuration Resolution
To bypass the WSL2 IPv6 proxy stall without modifying application source code, Docker image definitions, or backend services, an environment configuration file was created for the Vite frontend:

*File:* `src/frontend/.env`
```env
VITE_API_BASE_URL=http://127.0.0.1:8000/api/v1
VITE_WS_BASE_URL=ws://127.0.0.1:8000/api/v1/ws/stream
```

### Server Restart & Verification
The Vite frontend dev server was restarted cleanly on port 5173:
```bash
npm run dev
# Output: VITE v8.3.1 ready in 427 ms - Local: http://localhost:5173/
```

## 9. Phase 20 — Demo Operator Quick-Start Guide

For conducting the live demonstration:

### 1. Start System Stack
```bash
# Terminal 1: Start Backend Stack (Docker containers)
docker compose up -d

# Terminal 2: Start Frontend Dev Server
cd src/frontend
npm run dev
```

### 2. Verify System Health
```bash
curl http://127.0.0.1:8000/api/v1/health   # Part 2 Backend (Expect 200 OK)
curl http://127.0.0.1:8001/api/v1/health   # Part 1 Simulator (Expect 200 OK)
```

### 3. Open Command Center & Mobile App
- **Desktop Dashboard:** Open Chrome to `http://localhost:5173`
- **Android App:** Launch ARGUS Mobile on connected device (or install via `adb install -r part3/mobile/build/app/outputs/flutter-apk/app-debug.apk`)

### 4. Trigger Rapid Deterioration Demo Case
```bash
python -c "import urllib.request, json; req = urllib.request.Request('http://127.0.0.1:8001/api/v1/patients/PATIENT-001/scenario', data=json.dumps({'scenario_name': 'rapid_deterioration'}).encode(), headers={'Content-Type': 'application/json'}); print(urllib.request.urlopen(req).read().decode())"
```

### 5. Demonstrate Alert & Synchronization
1. Observe risk rising on Desktop Dashboard to **86%**.
2. Hear sound and feel vibration on Android phone when **RED URGENT** alert fires.
3. Tap mobile notification to view **Immediate Review**.
4. Tap **ACKNOWLEDGE ALERT** on phone → verify state changes to **ACKNOWLEDGED** on Desktop.

### 6. Shutdown System
```bash
docker compose down
```
